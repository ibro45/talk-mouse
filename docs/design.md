# Design (approved 2026-11-23)

**Why:** speak to an agent and send it without touching the keyboard. Every other button stays free for any use.

**Goals:** save the button setup for both mice, explain it at a glance, make applying it safe and reversible.
**Not goals:** DPI values, lighting, per-app remapping, other mouse models.

**Approaches for the picture:** animated SVG (chosen: sharp, small, plays in a README, works with motion off); GIF or video (heavier, blurry); interactive page (needs hosting).

**Decisions:** one key map drives the tool, tester and drawings. The drawing is a generic mouse. Dictation is bound on the computer, so any speech-to-text app works.
